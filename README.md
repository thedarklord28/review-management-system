# review-management-system
A closed-circle review management system made with Python and mySQL. Allows users to add reviews for services and products, and view reviews/average ratings product-wise, user-wise, category-wise, and location-wise.

The objective of this connectivity project is to design a Closed Network Review Management System which incorporates reviews of products based on categories 

The specific objectives are: 
1. View details of current users and products 
2. View all products and categories 
3. Allow users to add their own reviews and ratings 
4. Allow users to view reviews for a specific product/location/category. 
5. Allow users to view reviews posted by a specific user  
6. Access reviews posted by their family and friends 
7. Allow users to deactivate threads of conversation.

This project can be further built upon to incorporate more functionalities like allowing users to add new products and categories. This would find application in closed communities, like families, apartment complexes, or neighbourhoods to gain an overview of the general consensus within a circle of reliable individuals.
